一、业务分类管理流程

graph TD
    A[进入业务分类管理] --> B{操作类型}
    B -->|新增| C[点击「新增业务分类」]
    B -->|编辑| D[选择已有分类 → 点击「编辑」]
    B -->|删除| E[选择已有分类 → 点击「删除」]

    C --> F[填写分类名称、分类编码]

    L -->|否| M2{确认删除?}
    M2 -->|是| N[删除分类及关联权限]
    M2 -->|否| O[取消操作]

二、模版管理流程

2.1 模版组/模版 

graph TD
    A[进入模版管理] --> B{业务分类切换}
    B --> C[查看模版树]
    C --> D{操作类型}

    D -->|新建模版组| E[点击「新建模版组」]

    D -->|复制| N[选择模版 → 复制]

三、我发布的 — 信息发布流程

3.1 发布主流程

graph TD
    A[进入「我发布的」] --> B[选择业务分类]
    B --> C[选择模版]
    C --> D[点击「新建发布」]
    D --> E{填写方式}

    E -->|手动输入| F[手动填写模版表单]
    E -->|复制已发布信息| G[进入本模版下过往发布信息列表]
    G --> G1[选择过往信息一条]
    G1 --> G2[自动带入过往信息内容]
    G2 --> G3[支持修改过往发布信息的内容]

    F & G3 --> I[接收对象沿用模版设置 - 不可修改]
    I --> J{发布方式}

    J -->|立即发布| K[提交发布]
    J -->|定时发布| L[设置定时时间]
    L --> M[创建计划任务]
    J -->|保存草稿| N[存为草稿状态]

    K & M & N --> O[新建完成]

    style A fill:#d6eaf8,stroke:#2471a3
    style O fill:#d5f5e3,stroke:#1e8449
    style N fill:#f9e79f,stroke:#b7950b
    style G3 fill:#aed6f1,stroke:#2471a3
