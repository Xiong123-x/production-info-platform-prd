生产信息发布平台

面向工业生产场景的信息发布平台，覆盖模板管理、信息发布、信息接收与收藏全流程，支持定时 / 定期自动发布、外部共享与数据导出。

00前言

本文档为「生产信息发布平台」产品需求文档（PRD），当前版本覆盖 模板管理、我发布的、我收到的、我的收藏、发布列表 五大模块。

模板管理是平台的基础能力，负责业务分类维护、模板组层级管理、表单模板设计与发布规则配置；信息发布是平台的核心业务流程，基于模板完成信息填写、发布、定时 / 定期任务管理及数据导出；我收到的是信息接收方的工作台，支持收到信息的查看、已读管理、收藏及复制重新发布。

03文档说明 GLOSSARY

名词解释

业务分类

平台顶层组织维度，对应企业内部的业务部门或业务组（如动力能源部、铁区一体化业务组），是模板组和模板的归属根节点。

模板组

业务分类下的层级分组，支持多级嵌套，用于对模板进行分类管理（如制水车间、煤气车间）。

模板

信息发布的表单结构定义，包含表单字段、发布规则、定期发布配置、外部共享设置等，是发布信息的数据结构蓝本。

表单设计器

可视化拖拽式表单构建工具，支持从组件库选择字段拖入画布，配置字段属性，实时预览手机端 / 电脑端效果。

接收对象

模板配置的信息接收方范围，分为「指定成员」（模板固定）和「发起人自选」（发布时由发布人选择）两种模式。

组织人员

模板配置中固定的信息接收组织或人员，发布时信息将自动发送给这些对象。

当班人员

按班次动态匹配的接收人员，适用于交接班类场景，发布时自动匹配当前当班人员。

定期发布

模板级别的定时发布规则，开启后系统按配置的周期（间隔 / 天 / 周 / 月）自动触发信息发布。

外部共享

通过链接或二维码将模板数据对外共享，可配置共享字段、数据范围和链接有效期。

04需求背景

4.1产品现状

当前生产信息发布缺乏统一的模板化管理机制，各业务部门的信息发布格式不统一，字段定义分散，难以进行数据汇总和分析。同时，发布流程依赖人工操作，缺少定期自动发布能力，效率较低。

4.2用户调研

关键结论

  • 各车间（制水、煤气、燃气等）有大量重复性的日志、台账、记录类信息需要定期发布，格式相对固定
  • 用户希望通过可视化方式自定义表单字段，无需开发介入
  • 交接班场景需要按班次自动匹配接收人员
  • 部分数据需要对外共享（如挂牌信息），要求可控的链接访问权限

4.3竞品分析

维度 本产品 通用低代码平台 传统 OA 表单
业务分类层级 业务分类 → 模板组（多级）→ 模板，三级结构贴合工业场景 一般仅支持文件夹单层管理 按表单类型分类，无业务维度
表单设计 13 种工业常用组件，支持手机 / PC 双端预览 组件丰富但通用化，需额外配置 组件有限，定制化弱
发布规则 支持指定成员 / 发起人自选、组织人员 + 当班人员双轨、修改 / 撤回时限 一般仅支持固定接收人 流程审批导向，非信息发布
定期发布 模板级配置，支持间隔 / 天 / 周 / 月四种周期 需配合工作流实现 不支持

05需求范围

5.1本期范围

6.1业务分类管理

6.1.1功能概述

业务分类是平台的顶层组织维度，对应企业内部的业务部门或业务组。管理员可在此维护全部分类，分类下可挂载模板组和模板。端侧支持：仅 PC 端。

6.1.2业务分类列表

  • 页面入口：① 左侧导航栏 → 模版管理；② 模板管理页面左侧顶部业务分类下拉选择器 → 底部「新增业务分类」
  • 排序规则：以新建时间先后排序

6.1.3新增 / 编辑业务分类

交互方式：弹窗表单

字段必填长度限制规则说明
分类名称是≤ 200 字 名称不可重复；支持中英文、数字、特殊字符
分类编码是≤ 50 字 全局唯一；支持自动生成和手动输入，手动输入仅允许 大写字母、数字、下划线（_）、中划线（-）；自动生成规则 C + YYMMDD + 4位流水；创建后不可修改

6.1.4删除业务分类

  • 点击「删除」弹出二次确认弹窗，提示「删除后不可恢复」
  • 若该分类下存在模板组或模板，禁止删除，提示「该分类下存在模板组，请先清理后再删除」
  • 删除成功后，模板管理页面左侧业务分类下拉列表同步更新
  • 若在模板管理页面删除当前选中的业务分类，删除成功后自动切换到下拉列表中的第一个分类，并同步加载该分类下的模板组与模板

6.2模板管理主页

6.2.1页面布局

模板管理页面采用左右分栏布局：端侧支持：仅 PC 端。

  • 左侧栏：业务分类选择器 + 模板搜索框 + 模板组 / 模板树 + 新建按钮
  • 右侧主区域：模板详情展示（基本信息 + 权限配置 + 表单预览）

6.2.2业务分类选择器

  • 顶部下拉展示当前选中的业务分类，点击展开全部分类列表
  • 每个分类项右侧常驻显示「⋯」操作按钮，点击弹出「编辑」「删除」操作菜单
  • 下拉列表底部固定「＋ 新增业务分类」入口
  • 切换业务分类后，下方模板树刷新为该分类下的模板组和模板

6.2.3模板搜索

  • 搜索框支持按模板组名称、模板名称模糊匹配
  • 搜索结果在模板树中高亮匹配项，自动展开匹配项所在的分组
  • 清空搜索框后恢复完整树展示

6.2.4模板组 / 模板树

工具栏

  • 「📁 新建模版组」：在当前业务分类根节点下新建模板组
  • 「📄 新建模版」：打开模板编辑器，默认归属当前选中的模板组

新建模版组

字段必填长度限制规则说明
模版组名称是≤ 200 字 同一业务分类下名称不可重复
模版组编码是≤ 50 字 全局唯一；支持自动生成和手动输入，手动输入仅允许 大写字母、数字、下划线（_）、中划线（-）；自动生成规则 G + YYMMDD + 4位流水；创建后不可修改

模板组节点

  • 支持多级嵌套展开 / 收起，最多支持 5 级嵌套，点击箭头或模版组名称切换
  • 悬停显示「⋯」操作菜单，包含：新增子分组、重命名、删除
  • 删除模板组时，若组内存在模板（含已停用），禁止删除

模板节点

  • 点击模板节点，右侧展示该模板详情
  • 当前选中模板高亮显示
  • 悬停显示「⋯」操作菜单：启用模版、草稿模版、已停用模版操作包含：编辑、复制、停用 / 启用、删除，草稿模版操作菜单：编辑、复制、发布、删除
  • 模版标签：暂存模版后有「草稿」标签，设置了定期任务有「定期」标签
  • 已停用模板默认隐藏，每个模板组下有「展示已停用模版」复选框，勾选后显示该组下已停用模板（灰色文字）
  • 模版停用后在【我发布的】发布消息时不能被引用，仅支持查看停用模版下的历史发布列表，支持查看、收藏、删除历史引用该模版发布的消息

6.2.5模板详情

头部操作区

  • 模板名称 + 状态标签（正常已停用草稿定期）
  • 已启用模版详情页：编辑、复制、停用
  • 编辑已启用模版：预览、发布
  • 已停用模版详情页：编辑、复制、启用、删除
  • 编辑已停用模版：暂存、预览、发布，暂存后还是停用状态
  • 草稿模版详情页：编辑、复制、删除、发布

发布规则配置区

  • 电脑端：以表单形式展示字段布局，明细类字段以表格形式展示
  • 手机端：以手机外框模拟移动端展示效果
  • 组件动态渲染，预览为只读展示，不可编辑

6.3新增 / 编辑模版

6.3.1编辑器整体结构

  • 顶部操作栏：返回按钮、标题（新增模版 / 编辑模版）、暂存、预览、保存并发布
  • Tab 导航：基础设置 / 表单设计 / 高级设置
  • 内容区：根据 Tab 切换对应编辑界面

保存规则

  • 「暂存」：保存当前编辑内容为草稿状态，不发布，模板状态为「草稿」
  • 「保存并发布」：校验必填项后保存并发布，① 未设置定期发布，模板状态为「正常」；② 设置了定期发布，模版状态为「定期」
  • 编辑已有模板时，修改后「保存并发布」直接覆盖原模板；不能暂存
  • 未保存离开新增页面时弹出确认提示“当前填写的信息尚未暂存，离开后将全部清空。”

6.6信息发布

6.6.1功能概述

信息发布是平台的核心业务流程，用户基于已发布的模板填写表单内容，选择接收对象（或沿用模板配置），通过立即发布、定时发布方式将信息推送给目标人员。发布后可在「我发布的」中查看记录、进行修改或撤回操作，管理员可在「发布列表」中查看全量数据并导出。端侧支持：PC 端 + 移动端（发布列表仅 PC 端）。

6.7我收到的

6.7.1功能概述

「我收到的」是信息接收方的核心工作台，展示当前用户作为接收对象收到的全部发布信息。用户可在此按模板筛选、多条件检索、查看详情、标记已读 / 未读、收藏重要信息，并可将收到的信息复制后重新发布。侧边栏导航项显示未读数角标，帮助用户快速识别待处理信息。端侧支持：PC 端 + 移动端（移动端默认首页）。

与「我发布的」区别：

  • 我发布的：展示当前用户作为发布人发出的信息，可修改 / 撤回
  • 我收到的：展示当前用户作为接收对象收到的信息，可查看 / 已读 / 收藏 / 复制重新发布，不可修改或撤回原信息

页面入口：侧边栏「生产信息发布」→「我收到的」

消息通知：消息发布时在站内信消息中心推送一条通知，点击站内信消息详情可快速跳转到 "我收到的消息详情"

模板树筛选

  • 点击模板节点，右侧列表自动筛选为该模板的收到记录
  • 点击模板组节点展开 / 收起子节点，不触发筛选
  • 模板搜索框支持按模板组名称、模板名称模糊匹配，搜索结果高亮并自动展开
  • 未选中模板时，右侧展示全部收到的信息（跨模板），空状态提示「请从左侧选择模板」
