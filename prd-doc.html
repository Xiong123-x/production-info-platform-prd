00前言

本文档为「生产信息发布平台」产品需求文档（PRD），当前版本覆盖模板管理、我发布的、我收到的、我的收藏、发布列表五大模块。模板管理是平台的基础能力，负责业务分类维护、模板组层级管理、表单模板设计与发布规则配置；信息发布是平台的核心业务流程，基于模板完成信息填写、发布、定时/定期任务管理及数据导出；我收到的是信息接收方的工作台，支持收到信息的查看、已读管理、收藏及复制重新发布。

03文档说明

名词解释

业务分类

平台顶层组织维度，对应企业内部的业务部门或业务组（如动力能源部、铁区一体化业务组），是模板组和模板的归属根节点

模板组

业务分类下的层级分组，支持多级嵌套，用于对模板进行分类管理（如制水车间、煤气车间）

模板

信息发布的表单结构定义，包含表单字段、发布规则、定期发布配置、外部共享设置等，是发布信息的数据结构蓝本

表单设计器

可视化拖拽式表单构建工具，支持从组件库选择字段拖入画布，配置字段属性，实时预览手机端/电脑端效果

接收对象

模板配置的信息接收方范围，分为「指定成员」（模板固定）和「发起人自选」（发布时由发布人选择）两种模式

组织人员

模板配置中固定的信息接收组织或人员，发布时信息将自动发送给这些对象

当班人员

按班次动态匹配的接收人员，适用于交接班类场景，发布时自动匹配当前当班人员

定期发布

模板级别的定时发布规则，开启后系统按配置的周期（间隔/天/周/月）自动触发信息发布

外部共享

通过链接或二维码将模板数据对外共享，可配置共享字段、数据范围和链接有效期

04需求背景

产品现状

当前生产信息发布缺乏统一的模板化管理机制，各业务部门的信息发布格式不统一，字段定义分散，难以进行数据汇总和分析。同时，发布流程依赖人工操作，缺少定期自动发布能力，效率较低。

用户调研

关键结论： 各车间（制水、煤气、燃气等）有大量重复性的日志、台账、记录类信息需要定期发布，格式相对固定 用户希望通过可视化方式自定义表单字段，无需开发介入 交接班场景需要按班次自动匹配接收人员 部分数据需要对外共享（如挂牌信息），要求可控的链接访问权限

竞品分析

维度本产品通用低代码平台传统OA表单
业务分类层级业务分类 → 模板组（多级）→ 模板，三级结构贴合工业场景一般仅支持文件夹单层管理按表单类型分类，无业务维度
表单设计13种工业常用组件，支持手机/PC双端预览组件丰富但通用化，需额外配置组件有限，定制化弱
发布规则支持指定成员/发起人自选、组织人员+当班人员双轨、修改/撤回时限一般仅支持固定接收人流程审批导向，非信息发布
定期发布模板级配置，支持间隔/天/周/月四种周期需配合工作流实现不支持

05需求范围

本期范围：模板管理模块全量功能（业务分类管理、模板组管理、模板列表与详情、模板编辑器）+ 信息发布模块全量功能（发布入口、发布表单、定时/定期发布、我发布的、发布详情、发布后操作、定时任务管理、发布列表与数据导出）+ 我收到的模块全量功能（收到列表、多条件筛选、列表/卡片双视图、批量标记已读、收到详情、已读/未读管理、收藏管理、阅读情况、复制重新发布）。 端侧范围：PC端支持全部模块（模板管理、我发布的、我收到的、我的收藏、发布列表）；移动端仅支持我发布的、我收到的、我的收藏三个模块，模板管理与发布列表仅PC端可用。

06功能详细说明

6.1 业务分类管理

6.1.1功能概述

业务分类是平台的顶层组织维度，对应企业内部的业务部门或业务组。管理员可在此维护全部分类，分类下可挂载模板组和模板。端侧支持：仅PC端。

6.1.2业务分类列表

页面入口：① 左侧导航栏 → 模版管理；② 模板管理页面左侧顶部业务分类下拉选择器 → 底部「新增业务分类」

排序规则：以新建时间先后排序

6.1.3新增/编辑业务分类

交互方式：弹窗表单

字段必填长度限制规则说明
分类名称是≤200字名称不可重复；支持中英文、数字、特殊字符
分类编码是≤50字全局唯一；支持自动生成和手动输入，手动输入仅允许 大写字母、数字、下划线（_）、中划线（-）；自动生成规则C + YYMMDD + 4位流水；创建后不可修改

6.1.4删除业务分类

点击「删除」弹出二次确认弹窗，提示「删除后不可恢复」

若该分类下存在模板组或模板，禁止删除，提示「该分类下存在模板组，请先清理后再删除」

删除成功后，模板管理页面左侧业务分类下拉列表同步更新

若在模板管理页面删除当前选中的业务分类，删除成功后自动切换到下拉列表中的第一个分类，并同步加载该分类下的模板组与模板

6.2 模板管理主页

6.2.1页面布局

模板管理页面采用左右分栏布局：端侧支持：仅PC端。

左侧栏：业务分类选择器 + 模板搜索框 + 模板组/模板树 + 新建按钮

右侧主区域：模板详情展示（基本信息 + 权限配置 + 表单预览）

6.2.2业务分类选择器

顶部下拉展示当前选中的业务分类，点击展开全部分类列表

每个分类项右侧常驻显示「⋯」操作按钮，点击弹出「编辑」「删除」操作菜单

下拉列表底部固定「＋ 新增业务分类」入口

切换业务分类后，下方模板树刷新为该分类下的模板组和模板

6.2.3模板搜索

搜索框支持按模板组名称、模板名称模糊匹配

搜索结果在模板树中高亮匹配项，自动展开匹配项所在的分组

清空搜索框后恢复完整树展示

6.2.4模板组/模板树

工具栏：

「📁 新建模版组」：在当前业务分类根节点下新建模板组

「📄 新建模版」：打开模板编辑器，默认归属当前选中的模板组

新建模版组

字段必填长度限制规则说明
模版组名称是≤200字同一业务分类下名称不可重复
模版组编码是≤50字全局唯一；支持自动生成和手动输入，手动输入仅允许 大写字母、数字、下划线（_）、中划线（-）；自动生成规则 G + YYMMDD + 4位流水；创建后不可修改

模板组节点：

支持多级嵌套展开/收起，最多支持5级嵌套，点击箭头或模版组名称切换

悬停显示「⋯」操作菜单，包含：新增子分组、重命名、删除

删除模板组时，若组内存在模板（含已停用），禁止删除

模板节点：

点击模板节点，右侧展示该模板详情

当前选中模板高亮显示

悬停显示「⋯」操作菜单，启用模版、草稿模版、已停用模版操作包含：编辑、复制、停用/启用、删除，草稿模版操作菜单：编辑、复制、发布、删除

模版停用后在【我发布的】发布消息时不能被引用，仅支持查看停用模版下的历史发布列表，支持查看、收藏、删除历史引用该模版发布的消息

模版标签：暂存模版后有「草稿」状态，设置了定期任务有「定期」标签

已停用模板默认隐藏，每个模板组下有「展示已停用模版」复选框，勾选后显示该组下已停用模板（灰色文字）

6.2.5模板详情

操作区：

编辑已启用模版：预览、发布

已停用模版详情页：编辑、复制、启用、删除

编辑已停用模版：暂存、预览、发布，暂存后还是停用状态

草稿模版详情页：编辑、复制、删除、发布

基本信息区：

模版名称交接班日志+状态（启用/停用/草稿）
模版编码TPL-JBJRZ-001模版路径动力能源部/制水车间
创建时间2024-05-26 12:36最近更新时间2026-08-21 10:18

发布规则配置区：

接收对象显示「指定人员」或「发起人自选」；指定人员模式下标注「发起人发布的信息将送给指定成员，不能修改」；发起人自选模式下标注「发布信息时，由发起人自主指定该信息的接收成员」
组织人员以标签形式展示，点击「修改」打开通讯录选择器
当班人员以标签形式展示，未配置时显示「--」，点击「修改」打开通讯录选择器

表单预览区：

支持「电脑端」「手机端」Tab切换预览

电脑端：以表单形式展示字段布局，明细类字段以表格形式展示

手机端：以手机外框模拟移动端展示效果

组件动态渲染，预览为只读展示，不可编辑

6.3 新增/编辑模版

6.3.1编辑器整体结构

顶部操作栏：返回按钮、标题（新增模版/编辑模版）、暂存、预览、保存并发布

Tab导航：基础设置 / 表单设计 / 高级设置

内容区：根据Tab切换对应编辑界面

保存规则： 「暂存」：保存当前编辑内容为草稿状态，不发布，模板状态为「草稿」 「保存并发布」：校验必填项后保存并发布，①未设置定期发布，模板状态为「正常」；②设置了定期发布，模版显示「定期」标签 编辑已有模板时，修改后「保存并发布」直接覆盖原模板；不能暂存 未保存离开新增页面时弹出确认提示“当前填写的信息尚未暂存，离开后将全部清空。” 设置了定期发布，但接收对象选择的【发起人自选】，点击【暂存】和【保存并发布】需要提示“定期任务需要设置接收对象” 接收对象选择了【指定接收人】但未设置当班人员、组织人员，点击【暂存】和【保存并发布】时需要提示“请选择接受对象” 【预览】查看设置的表单设计和模版标题

6.3.2基础设置

总开关：默认关闭，开启后显示规则配置区，提示“设置发布周期后，需要指定接收对象，系统将按此规律自动执行，无需重复手动操作”

只有接收对象是【指定成员】时才会出现

执行周期规则类型：按照Cron表达式组件，设置时、天、周、月

规则类型配置项
按小时间隔数值 + 单位（小时）；如「每隔2小时」,最短时间间隔1小时
按天每天固定时间点（可添加多个时间点，如 08:00、20:00）

按月选择每月几号（可多选）+ 固定时间点（可多个）

6.6 信息发布

6.6.1功能概述

信息发布是平台的核心业务流程，用户基于已发布的模板填写表单内容，选择接收对象（或沿用模板配置），通过立即发布、定时发布方式将信息推送给目标人员。发布后可在「我发布的」中查看记录、进行修改或撤回操作，管理员可在「发布列表」中查看全量数据并导出。端侧支持：PC端 + 移动端（发布列表仅PC端）。

6.6.2发布入口与模板选择

页面入口：侧边栏「生产信息小报」→「我发布的」

页面布局：左右分栏

左侧栏：业务分类选择器 + 模板搜索框 + 模板组/模板树

右侧主区域：发布信息列表（筛选区 + 列表 + 分页）

模板选择与发布入口：

左侧模板树中点击某个模板节点，右侧列表自动筛选为该模板的发布记录

选中模板后，右侧列表顶部出现「+ 发布信息」按钮，点击进入发布表单页面

未选中模板时，「+ 发布信息」按钮不显示，提示「请先在左侧选择模板」

已停用模板仅支持查看历史发布信息列表和信息详情，不支持引用停用模版发布消息，不支持复制已停用模版发布的消息

6.6.3发布表单填写

顶部操作栏：返回按钮 + 页面标题（发布信息 / 编辑发布信息）+ 模板名称标签

表单字段：

字段必填规则说明
信息标题必填单行输入框，最长200字符；默认自动填充为「模板名称 + 当前日期」，可手动修改
模板字段区视模板配置根据所选模板的表单设计动态渲染字段，包括单行/多行输入、数字、单选、日期、明细、图片/文件上传、链接、选择器、人员/组织选择等；模板中标记为必填的字段发布时校验
明细字段视模板配置动态增删行的子表格，支持添加行、删除行、行内编辑；受模板配置的最大/最小行数限制
接收对象必填沿用模板配置，发布时不可修改，指定成员模式下展示固定接收人；发起人自选模式，由发布人选择接收对象组织人员、当班人员

底部操作栏：

操作按钮说明

发布校验必填项后立即发布，信息发送给接收对象；发布后状态为「已发布」
定时发布点击展开定时配置面板，选择发布时间后保存，状态为「定时待发布」，到点自动发布
预览支持切换手机端、电脑端查看

编辑模式差异：编辑已发布信息时，底部按钮变为「更新发布」「预览」；仅模板配置中允许修改的字段可编辑，其余字段只读展示。

复制已发布信息

在发布信息页面，点击「复制已发布信息」按钮，弹出同模板自己历史已发布记录列表

列表展示：信息标题、发布时间，支持按标题搜索

选择一条记录后，该记录的全部字段值回填到当前表单中，信息标题自动追加「- 副本」后缀

用户可在复制内容基础上修改后发布，适用于重复性日志/台账类场景

复制操作不影响原记录

复制已发布消息，回填内容以最新模版内容为准，如历史模版表单有A、B、C、D，最新模版表单只有A、B、C，复制后只回填A、B、C内容

获取数据

模版中设置了从数据源中获取数据，在发布消息时可以点击【获取数据】刷新最新数据填写

6.6.4定时发布与定期发布

定时发布（单次）：

点击「定时发布」展开配置面板

6.7 我收到的

6.7.1功能概述

「我收到的」是信息接收方的核心工作台，展示当前用户作为接收对象收到的全部发布信息。用户可在此按模板筛选、多条件检索、查看详情、标记已读/未读、收藏重要信息，并可将收到的信息复制后重新发布。侧边栏导航项显示未读数角标，帮助用户快速识别待处理信息。端侧支持：PC端 + 移动端（移动端默认首页）。

复制操作不影响原信息，原信息的已读状态和收藏状态不变

若用户在撤回前已经收藏，撤回后在收藏列表显示「已撤回」标签，不可查看详情、不可收藏、不可复制

6.8 我的收藏

6.8.1功能概述

「我的收藏」模块集中展示当前用户在「我发布的」和「我收到的」中标记为收藏的所有信息，提供统一的收藏内容管理入口。用户可在此快速查找、查看和取消收藏，支持按来源、分类、时间等多维度筛选，并提供列表和卡片两种浏览视图。端侧支持：PC端 + 移动端（移动端底部Tab「我的收藏」）。

6.8.2页面入口

页面入口：侧边栏「生产信息发布」→「我的收藏」

收藏入口共三处：「我发布的」列表操作列/详情页、「我收到的」列表操作列/卡片底部/详情页，三处收藏状态实时同步

6.8.3筛选区

页面顶部筛选栏包含以下筛选项，各条件之间为 AND 关系：

筛选项控件类型说明
关键字搜索文本输入框 + 搜索按钮按信息标题模糊匹配，输入后实时过滤
收藏时间日期范围选择器开始时间 ~ 结束时间，按收藏操作时间过滤
来源下拉选择全部 / 我发布的 / 我收到的
分类下拉选择全部分类 / 具体收藏的消息来源业务分类（如动力能源部/制水车间、动力能源部/煤气车间、轧钢生产等）

6.8.4视图切换

筛选栏下方提供视图切换标签，支持两种展示模式：

列表展示（默认）：以表格形式展示收藏内容，信息密度高，适合快速浏览和批量管理

卡片展示：以卡片形式展示，包含发布人、字段摘要等更多信息，适合内容预览

切换视图时保留当前筛选条件和搜索结果

右侧显示当前筛选结果总数：「共 X 条」

6.8.5列表视图

列表视图字段结构如下：

列名说明
标题标题后附带来源标签（「我发布的」/「我收到的」）
分类业务分类路径，如「动力能源部/制水车间」，无分类时显示「-」
来源「我发布的」或「我收到的」
发布人发布人姓名，无则显示「-」
收藏时间信息收藏时间，格式 YYYY-MM-DD HH:mm:ss
发布时间信息发布时间，格式 YYYY-MM-DD HH:mm:ss
操作「详情」链接：跳转到对应来源的详情页；「取消收藏」链接：取消该条收藏，取消后从列表中移除

6.8.6卡片视图

卡片视图以响应式网格排列，每张卡片包含以下元素：

卡片头部：发布人头像（取姓名首字）、发布人姓名、发布时间、来源标签（右上角）

信息标题：信息标题，已撤回信息显示「已撤回」标签

内容摘要：取该模板前两个表单字段的值进行预览，单个字段值超过40字符时截断并显示「...」

卡片底部：左侧显示业务分类（📂图标 + 分类名），右侧显示「★ 取消收藏」按钮（橙色文字）

点击卡片主体区域跳转到对应来源的详情页；点击「取消收藏」按钮时阻止事件冒泡，仅执行取消收藏操作

6.8.7空状态

当用户没有任何收藏内容，或当前筛选条件下无匹配结果时，显示空状态

空状态展示：「暂无收藏内容」文字提示

引导用户前往「我发布的」或「我收到的」模块进行收藏操作

6.8.8操作与交互

查看详情：点击标题、卡片主体或「详情」链接，根据来源字段跳转到对应模块的详情页（来源为「我发布的」则打开发布详情，来源为「我收到的」则打开收到详情）

取消收藏：

列表视图：点击操作列「取消收藏」链接

卡片视图：点击卡片底部「★ 取消收藏」按钮

取消后显示 Toast 提示「已取消收藏」，列表实时刷新，该条记录从当前视图移除

取消收藏后，「我发布的」和「我收到的」中对应记录的收藏按钮状态同步更新为未收藏

已撤回的信息不可收藏，若收藏后被发布人撤回，该记录仍保留在收藏列表中，不可查看详情

6.8.9数据来源与同步机制

收藏数据合并自两个来源：「我发布的」中用户收藏的记录 + 「我收到的」中用户收藏的记录

每条收藏记录包含 source 字段标识来源（published / received），用于详情页跳转路由

收藏状态在以下位置实时同步：「我的收藏」列表、「我发布的」列表/详情、「我收到的」列表/卡片/详情，任意一处收藏/取消收藏，其余位置状态即时更新

收藏操作记录收藏时间，用于「收藏时间」筛选

收藏数据按用户隔离，每位用户仅能查看和管理自己的收藏内容
